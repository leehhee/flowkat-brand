Foundation

Color

FlowKat 색상 시스템은 화면의 위계와 상태, 브랜드를 일관되게 표현하도록 돕습니다.

Overview

FlowKat 색상은 역할 기반 색상과 팔레트 색상으로 나뉩니다. 화면에는 역할 기반 색상을 쓰고, 팔레트 색상은 역할 기반 색상을 만드는 재료로 씁니다.

색상 원칙

  • 주황은 선으로: 브랜드 주황은 강한 색이라 면으로 채우면 경고나 에러로 오해할 수 있습니다. 활성 상태와 강조가 필요한 곳에만 얇은 선으로 씁니다.
  • 명암으로 위계: 색을 늘리지 않고, 같은 회색 계열의 밝기 차이로 정보의 위계를 구분합니다.
  • 면보다 선: 꽉 찬 면은 최소화하고, 선 위주로 가볍게 구분합니다.

Role Based Color

역할 기반 색상은 색마다 쓰임을 정해 둔 것입니다. 임의의 색상값 대신 text/primary, border/default처럼 역할로 색을 고르면, 디자인과 개발이 같은 기준으로 화면을 만들 수 있습니다.

장점 1. 일관된 위계

같은 역할에는 언제나 같은 색이 쓰입니다. 글자, 테두리, 아이콘이 각각 정해진 단계 안에서 움직여 화면 어디서든 위계가 같게 보입니다.

[이미지: 위젯 카드 하나: 제목 text/primary, 값 text/normal, 보조 text/sub, 카드 선 border/default 칩]

장점 2. 빈틈없는 업데이트

색은 값이 아니라 의미를 기준으로 바꿉니다. text/active와 border/active는 같은 주황이지만 역할이 달라, 필요하면 하나만 따로 바꿀 수 있습니다.

[이미지: 탭 바: 활성 탭 글자 text/active와 밑줄 border/active (같은 주황, 다른 이름)]

장점 3. 테마 적응성

역할 기반 색상은 라이트 모드와 다크 모드에서 각각 맞는 값을 가리킵니다. 한 가지 모드로 디자인해도 다른 모드에서 위계와 대비가 유지됩니다.

[이미지: 같은 카드를 라이트/다크로 나란히, 칩 이름은 같고 HEX만 다름]

Palette Color

팔레트 색상은 역할 기반 색상을 이루는 원래 값입니다. 화면에 직접 쓰지 않고, 역할로 표현하기 어려운 예외에만 씁니다.

[이미지: CN 스케일 99→5 한 줄 띠]

Usage Guidelines

  • Don't 주황으로 면 채우기

    브랜드 주황은 선으로만 씁니다.

  • Don't 브랜드 주황을 상태색으로 쓰기

    주황은 에러, 경고와 헷갈리므로 상태 표시에 쓰지 않습니다.

  • Don't 테두리와 배경색 함께 쓰기

    영역은 테두리나 배경색 중 하나로만 구분합니다.

FlowKat의 역할 기반 색상은 Property(속성), Role(역할), State(상태) 체계로 구성되어 있습니다.

Property (속성)

Background, Text, Border, Icon 네 가지 기본 속성으로 시작합니다.

Background

전체 화면 또는 UI의 배경에 사용하는 색상입니다.

Text

글자에 사용하는 색상입니다.

Border

경계를 구분하는 선 또는 UI 요소의 윤곽선에 사용하는 색상입니다.

  • 카드·위젯처럼 선이 요소의 외곽을 그릴 때는 border/default를 사용합니다.
  • 테이블 행, 차트 그리드처럼 반복되는 구분에는 border/faint를 사용합니다.
  • 테이블 헤더 하단처럼 섹션의 층위를 나눌 때는 border/subtle을 사용합니다.

Icon

아이콘에 사용하는 색상입니다. 같은 자리의 글자와 같은 단계로 맞춰 씁니다.

Role (역할)

속성에 더해 Layer, Neutral, Active, Critical 같은 역할로 색상을 묶습니다. 같은 역할은 속성이 달라도 같은 의미를 가지며, 화면 전반에서 일관되게 쓰입니다.

Layer

레이어 색상은 화면의 깊이와 층을 나타냅니다. base 위에 surface-1이 올라오고, 입력 요소는 input, 화면 위에 떠 있는 요소는 tooltip을 씁니다.

  • bg/base
  • bg/surface-1
  • bg/input
  • bg/tooltip

Neutral

일반 콘텐츠에 쓰는 기본 색상입니다. 위계는 색을 늘리지 않고 명암 차이로 나눕니다.

  • text/primary
  • text/normal
  • text/sub
  • text/disabled
  • border/default
  • border/faint
  • border/subtle
  • border/highlights
  • icon/primary
  • icon/subtle
  • icon/faint

Active

선택된 탭, 메뉴, 포커스처럼 활성 상태를 나타냅니다. 브랜드 주황을 쓰며, 면으로 채우지 않고 선과 글자로만 표현합니다.

  • text/active
  • border/active
  • icon/active

Critical

에러가 발생한 데이터를 강조합니다.

  • bg/critical-subtle

State (상태)

UI 요소의 상태에 따라 색상이 바뀝니다. 테이블 행이나 리스트 항목에 마우스를 올리면 bg/hover가 쓰입니다.

  • bg/hover

상태와 지연(Latency) 색은 같은 Status 팔레트를 참조합니다. 비동기(async)는 Neutral CN/80을 씁니다.

지연 색상은 안전색채를 기반으로 정했습니다. 매우 느림 단계에 주황 대신 분홍을 쓴 것은 에러를 뜻하는 빨강, 브랜드 주황과 헷갈리지 않게 하기 위해서입니다. XLog와 액티브 서비스는 같은 지연 토큰 6개를 참조합니다.
