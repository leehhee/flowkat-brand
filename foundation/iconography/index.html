Iconography

아이콘은 기능과 정보를 글보다 빠르게 전달합니다. FlowKat 아이콘은 가는 선으로 가볍게 그려, 데이터가 많은 화면에서도 정보를 가리지 않습니다.

기반

FlowKat 아이콘은 Google Material Symbols의 Outlined 스타일을 FlowKat에 맞게 조정해 씁니다.

항목값
StyleMaterial Symbols, Outlined
Fill0 (Fill 아이콘만 1)
Weight200
Grade0
Optical Size24

Categories

Line

기본 아이콘입니다. 모든 아이콘은 선으로 그립니다.

Fill

차트 영역에 속한 중요한 아이콘과 상태 표시에만 면을 씁니다. 예: 뷰 토글, 완료·에러 상태.

[이미지(iconography-fill.svg): Fill 쓰는 곳: 차트 뷰 토글(view-list-fill)과 상태 아이콘(check-circle-fill, error-fill)]

Naming Convention

아이콘 이름은 확장성을 위해 형상만을 고려해 짓습니다. Material Symbols에 같은 아이콘이 있으면 그 이름을 그대로 쓰고, 면 아이콘은 이름 끝에 -fill을 붙입니다. 예: info, info-fill.

아이콘이 쓰이는 메뉴나 기능은 이름 대신 설명에 적어, 설명으로도 찾을 수 있게 합니다.

Creation Guide

FlowKat에서 쓰는 아이콘은 Library에서 먼저 찾습니다. 새 아이콘이 필요하면 아래 순서를 따릅니다.

  1. Material Symbols에서 같은 의미의 아이콘을 찾습니다.
  2. 위 기반 수치로 맞춰 가져옵니다.
  3. 맞는 아이콘이 없으면 브랜드 디자인 담당자에게 요청합니다.

Size

아이콘은 놓이는 자리에 따라 네 단계 크기를 씁니다. 최소 크기는 12px입니다.

이름값
$layout.icon-lgGNB, LNB, 패널, 다이얼로그처럼 박스 없이 단독으로 놓이는 아이콘 크기에 사용합니다.24px
$layout.icon-md리스트, 드롭다운, 검색창처럼 목록이나 입력 요소 안의 아이콘 크기에 사용합니다.20px
$layout.icon-sm버튼, 테이블, 배지처럼 박스 안에 들어가는 아이콘 크기에 사용합니다.16px
$layout.icon-xs상태 표시처럼 글자 옆에 붙는 작은 아이콘 크기에 사용합니다.12px
[이미지(iconography-size.svg): search 아이콘 24·20·16·12px 크기와 각각 쓰는 자리]

Color

아이콘 색은 icon 역할 색상을 씁니다. 활성 상태에만 주황(icon/active)을 씁니다.

이름값
$color.icon.primary헤더 기능 아이콘처럼 잘 보여야 하는 아이콘에 사용합니다.참조 $color.cn.20참조 $color.cn.97
$color.icon.subtle보조 기능과 선택되지 않은 메뉴 아이콘에 사용합니다.참조 $color.cn.50참조 $color.cn.60
$color.icon.faint배경에 가깝게 약하게 보이는 장식용 아이콘에 사용합니다.참조 $color.cn.97참조 $color.cn.20
$color.icon.active선택된 메뉴 등 활성 상태의 아이콘에 사용합니다.참조 $color.brand.accent.orange참조 $color.brand.accent.orange

색상 역할은 Color > Roles를 참고하세요.

Variants

Line

기본 상태와 대부분의 UI 아이콘에 씁니다.

Fill

차트 영역의 중요한 아이콘과 상태 표시에만 씁니다. 같은 아이콘의 Line과 Fill은 비활성과 활성처럼 상태를 나눌 때 함께 씁니다.

[이미지(iconography-variants.svg): Line↔Fill 짝: info/info-fill, check-circle/check-circle-fill, 비활성/활성]

With Typography

  • 아이콘과 글자 사이는 spacing/gap-3(8px)을 둡니다.
  • 아이콘과 글자는 높이 기준으로 가운데 정렬합니다.
  • 글자 크기에 맞는 아이콘 크기를 씁니다: 14px 글자 ↔ 16px 아이콘, 16px 글자 ↔ 20px 아이콘.
[이미지(iconography-with-typography.svg): 버튼(14px 글자+16px 아이콘)과 검색창(16px 글자+20px 아이콘), 사이 간격 8px]

Usage Guidelines

  • Don't 면 아이콘 남용

    차트 영역 밖에서는 Line 아이콘만 씁니다.

  • Don't 정해지지 않은 크기

    24, 20, 16, 12px 외의 크기로 쓰지 않습니다.

  • Don't 활성 상태 외의 주황

    주황은 활성 상태에만 씁니다.
