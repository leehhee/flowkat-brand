Foundation

Spacing

Spacing은 컴포넌트와 콘텐츠 사이의 간격을 표현합니다.

Purpose

간격은 화면의 균형과 읽기 흐름을 만듭니다. FlowKat은 정해진 간격 단계만 써서 화면 전체에 같은 리듬을 유지합니다.

  • 일관성 유지: 모든 레이아웃과 컴포넌트에 같은 간격 단계를 씁니다.
  • 단계 관리: gap-1, padding-1처럼 미리 정한 단계로 간격을 고릅니다.
  • 가독성: 여백으로 정보 묶음을 나눠, 데이터가 많은 화면에서도 구분이 쉽게 합니다.

Gap (요소 사이 간격)

요소와 요소 사이의 간격입니다.

버튼 안 글자와 아이콘

spacing/gap-3(8px)을 씁니다.

[이미지(spacing-button-icon.svg): 버튼 "+ 생성하기"의 아이콘과 글자 사이 gap-3 8px 치수]

탭, 메뉴, 카드, 위젯 사이

LNB 메뉴, 탭, 카드, 대시보드 위젯처럼 같은 종류의 요소를 나열할 때는 spacing/gap-4(12px)를 씁니다. 위젯 격자는 가로·세로 모두 같습니다.

[이미지(spacing-tab-menu-card-widget.svg): 탭, LNB 메뉴, 위젯 격자 사이 gap-4 12px 치수]

섹션 사이

화면 안에서 내용 묶음을 나눌 때는 spacing/gap-8(32px)을 씁니다.

[이미지(spacing-section.svg): 화면 섹션 두 개 사이 gap-8 32px 치수]

필터 칩 사이

spacing/gap-3(8px)을 씁니다.

[이미지(spacing-filter-chip.svg): 필터 칩 사이 gap-3 8px 치수]

Padding (요소 안쪽 여백)

요소의 테두리와 내용 사이의 여백입니다.

버튼 여백

위아래는 spacing/padding-2(4px), 양옆은 spacing/padding-5(12px)를 씁니다.

[이미지(spacing-button-padding.svg): 버튼 위아래 4px, 양옆 12px 여백 치수]

Page Padding

대시보드 메인 콘텐츠와 화면 가장자리 사이의 여백입니다. 기본은 Page/Padding-Default(24px)를 쓰고, 정보량이 많은 화면은 Page/Padding-Compact(12px)를 씁니다.

[이미지(spacing-page-padding.svg): 같은 대시보드를 Default(24px)와 Compact(12px) 여백으로 비교]

Modal and Panel (모달·패널 안 간격)

모달과 사이드 패널 안의 간격은 아래 단계를 따릅니다. 관계가 멀수록 간격이 커집니다.

단계간격쓰임
밀착spacing/gap-2(4px)라벨과 입력칸 사이
항목spacing/gap-3(8px)버튼 사이, 목록 항목, 아이콘과 글자
필드spacing/gap-4(12px)입력 필드와 입력 필드 사이
제목spacing/gap-5(16px)패널 제목과 내용 사이
섹션spacing/gap-8(32px)섹션과 섹션 사이
영역spacing/gap-10(48px)큰 모달의 헤더와 본문 사이
  • 사이드 패널 안쪽 여백은 Page/Padding-Default(24px), 확인 대화상자는 spacing/padding-6(16px)입니다.
  • 하단 버튼 영역은 위에 border/default 0.5px 구분선을 두고, 선 위아래로 spacing/gap-5(16px)를 띄웁니다.
[이미지(spacing-modal-panel.svg): 고급 검색 패널: 라벨↔입력 4, 필드 사이 12, 제목↔내용 16, 구분선 위아래 16]

Typography

타이포그래피는 대시보드의 데이터와 콘텐츠를 명확하고 일관되게 읽히도록 정리한 글자 규칙입니다.

Layout

FlowKat 화면은 GNB, LNB, 본문, 사이드 패널로 나뉩니다. 영역마다 자리와 크기를 정해 어느 화면에서도 같은 구조를 유지합니다.
