Radius

Radius는 컴포넌트와 콘텐츠 모서리의 둥글기를 표현합니다.

Radius는 UI 요소의 모서리를 둥글게 처리해 형태를 구분합니다. 같은 종류의 요소에는 같은 Radius를 써서 화면 전체의 인상을 일정하게 유지합니다.

FlowKat은 웹과 모바일에서 다른 Radius를 씁니다. 웹은 데이터가 많은 화면에 맞춰 각진 모서리를, 모바일은 손가락으로 누르기 쉬운 둥근 모서리를 씁니다.
