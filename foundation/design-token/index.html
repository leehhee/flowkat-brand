Design Token

디자인 토큰은 디자인 결정을 이름 붙은 값으로 정리해, 디자인과 개발이 같은 언어로 쓰게 하는 방법입니다.

디자인 토큰이 무엇인가요?

디자인 토큰은 색상, 글자, 간격, 모서리처럼 화면을 이루는 값에 이름을 붙인 것입니다. #F4F4F5 대신 bg/surface, 12px 대신 spacing/gap-4처럼 이름으로 쓰면, 값이 바뀌어도 이름을 쓴 모든 곳이 함께 바뀝니다.

FlowKat 디자인 토큰의 구성

FlowKat 디자인 토큰은 세 단계로 나뉩니다.

Raw Value는 실제 값입니다. #FF4E0F, 8px처럼 색상 코드와 수치 그대로입니다.

Primitive Token은 Raw Value에 이름을 붙인, 쓸 수 있는 값의 목록입니다. 회색 스케일 cn/99~cn/5, 상태 색 status/green, 브랜드 색 brand/accent/orange(#FF4E0F) 등이 해당합니다.

Semantic Token은 Primitive Token에 쓰임을 붙인 것입니다. icon/active는 brand/accent/orange를 가리키고, brand/accent/orange는 #FF4E0F를 가리킵니다. 실제 디자인과 개발에서는 Semantic Token을 씁니다.

크기 토큰은 Primitive 단계 없이 Raw Value에 바로 쓰임 이름을 붙입니다. 예: spacing/gap-3 = 8px, radius/button = 4px(웹).

Semantic Token은 모드에 따라 다른 값을 가리킵니다. 같은 이름이 라이트 모드와 다크 모드, 웹과 모바일에서 각각 맞는 값으로 바뀝니다.

FlowKat 디자인 토큰의 예시

색상 토큰

icon/active, text/active, border/active 토큰은 모든 화면에서 선택된 메뉴와 탭을 같은 주황으로 표시하도록 돕습니다.

간격 토큰

화면 가장자리와 콘텐츠 사이 여백을 나타내는 spacing/page/padding-default 토큰은 모든 대시보드에서 같은 여백을 쓰도록 돕습니다.
