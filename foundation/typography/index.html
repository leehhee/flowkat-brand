Typography

타이포그래피는 대시보드의 데이터와 콘텐츠를 명확하고 일관되게 읽히도록 정리한 글자 규칙입니다.

FlowKat 타이포그래피는 글꼴, 크기, 줄 높이, 굵기를 조합한 텍스트 스타일로 관리합니다. 정해진 스타일만 써서 화면 어디서든 같은 위계로 읽히게 합니다.

글꼴

글자는 Pretendard, 숫자는 Roboto를 씁니다. 숫자를 별도 글꼴로 나누면 자릿수 폭이 일정해 표와 차트에서 값을 비교하기 쉽습니다.

용도글꼴
글자(한글, 영문)Pretendard
숫자(수치, 시간, 날짜)Roboto

텍스트 스타일 이름은 역할/크기-굵기로 짓습니다. 예를 들어 body/md-medium은 본문 역할, 중간 크기, Medium 두께입니다.

Usage Guidelines

  • 정해진 스타일: 크기나 굵기를 임의로 바꾸지 않고, 정해진 텍스트 스타일만 씁니다.
  • 숫자 표기: 숫자로 된 값은 모두 Roboto 기반의 number 스타일을 씁니다.
  • 정렬: 글자와 날짜는 왼쪽, 숫자 데이터는 오른쪽으로 정렬해 데이터 종류를 구분합니다.
  • 위계: 색을 늘리지 않고, 텍스트 스타일의 크기와 굵기 단계로 구분합니다.
