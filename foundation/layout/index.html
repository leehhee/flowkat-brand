Foundation

Layout

FlowKat 화면은 GNB, LNB, 본문, 사이드 패널로 나뉩니다. 영역마다 자리와 크기를 정해 어느 화면에서도 같은 구조를 유지합니다.

Purpose

대시보드는 많은 데이터를 한 화면에 보여 줍니다. FlowKat은 영역의 자리와 크기를 고정해, 화면이 바뀌어도 같은 자리에서 같은 기능을 찾게 합니다.

  • 고정된 틀: GNB와 LNB는 모든 화면에서 같은 자리, 같은 크기입니다.
  • 넓은 본문: 탐색 영역을 얇게 두어 데이터에 가장 넓은 공간을 줍니다.
  • 제자리 상세: 상세 정보와 편집은 화면을 옮기지 않고 오른쪽 패널에서 엽니다.

Layout Regions

화면은 다섯 영역으로 나뉩니다.

[이미지(layout-regions.svg): Layout Regions: GNB, LNB, Toolbar, Main Content, Side Panel]

GNB

화면 맨 위, 전체 폭을 차지하는 영역입니다. 서비스 로고, 현재 페이지 제목, 알림·도움말·프로필이 놓입니다.

  • 높이는 layout/gnb-height(44px)입니다. 모바일에서는 56px입니다.
  • 양옆 여백은 spacing/padding-3(8px)입니다.

LNB

화면 왼쪽의 메뉴 영역입니다. 아이콘 바와 메뉴 패널로 이루어집니다.

  • 아이콘 바의 폭은 layout/lnb-width(40px)이고 모든 화면에 늘 보입니다.
  • 하위 메뉴가 있는 모니터링, 인시던트 관리, 관리콘솔은 메뉴 패널(140px)을 함께 열어 전체 180px이 됩니다.
  • 모바일에서는 LNB를 숨깁니다.

Toolbar

본문 맨 위의 도구 영역입니다. 필터, 기간 선택, 화면 동작 버튼이 놓입니다.

  • 높이는 44px입니다.
  • 위아래 여백은 spacing/padding-3(8px), 양옆 여백은 Page/Padding-Default(24px)입니다.

Main Content

위젯과 표가 놓이는 핵심 영역입니다.

  • 가장자리 여백은 Page/Padding-Default(24px)입니다. 정보량이 많은 화면은 Page/Padding-Compact(12px)를 씁니다.

Side Panel

화면 오른쪽에서 열리는 패널입니다. 알림 상세, 이슈 상세, 위젯 편집처럼 선택한 항목의 정보와 설정을 다룹니다.

  • 폭은 680px입니다.
  • 안쪽 여백은 Page/Padding-Default(24px)입니다. 패널 안 간격은 Spacing > Modal and Panel을 따릅니다.
[이미지(layout-side-panel.svg): Side Panel이 열린 화면: 여백 24, 섹션 사이 32, 하단 구분선]

Widget Grid

대시보드 위젯은 10열 격자에 놓입니다. 열 폭은 화면 폭에 맞춰 늘어나고 줄어듭니다.

  • 위젯 사이 간격은 가로·세로 모두 spacing/gap-4(12px)입니다.
  • 위젯은 크기에 따라 정해진 칸 수를 차지합니다.
[이미지(layout-grid-anatomy.svg): Widget Grid 구조: 10열, 열 사이 간격 12, 가장자리 여백 24]

Screen Size

FlowKat은 1920×1080 데스크톱 화면을 기준으로 설계합니다.

단계화면 폭규칙
Desktop1280px 이상10열 격자를 유지하고 열 폭만 줄어듭니다.
1280px 미만—화면을 줄이지 않고 가로로 스크롤합니다.
Mobile767px 이하별도 화면을 씁니다. GNB가 56px로 높아지고 LNB를 숨기며, 위젯은 한 줄에 하나씩 쌓습니다.
[이미지(layout-responsive.svg): 1920px과 1280px에서의 Widget Grid: 10열 유지, 열 폭만 줄어듦]

Spacing

Spacing은 컴포넌트와 콘텐츠 사이의 간격을 표현합니다.

Radius

Radius는 컴포넌트와 콘텐츠 모서리의 둥글기를 표현합니다.
